**Leg uit wat een source hosting platform is en voor welke jij gekozen hebt.**
<br>
<br>
Een source hosting platform is een platform waar mensen de source code van hun website op kunnen slaan. Ik heb gekozen voor Github, omdat deze aanbevolen was door de docenten. Omdat ik zelf weinig programmeerervaring heb, lijkt het mij handiger om de programma's te kiezen waar het meeste informatie overstaat op DLO.
<br>
